**Longshot by team magicbean.** This local preview introduces the new name,
the Longshot artwork and the green, red and blue magicbean characters.

## This preview

The front page brings together guides, help and project updates. The branding
artwork was supplied for this preview and is used unchanged.

The reference manual, contribution guide and compatibility rules use this Longshot
checkout. Historical release information and the activity feed come from a dated
Hookshot snapshot. References to Hookshot,
its releases and its contributors retain their original names and attribution.
Follow Longshot development in
[the team magicbean repository](https://git.magicbean.dev/MagicBeanDev/Longshot).
Historical releases, reports and source references continue to link to
[NotRexed/Hookshot](https://github.com/NotRexed/Hookshot), with their original attribution.
The existing feed does not yet show Longshot activity.

This branch contains the website preview source. Pushing it does not deploy a website.

## Game files

We do not host, store or distribute game files, ROMs, game dumps or decryption
keys. You must supply your own supported copy and build locally.

## Using the guides

Browse the documentation or search with **Ctrl/Cmd + K**. The problem search
looks through the dated Hookshot report snapshot. Search terms stay in your
browser. Reports and merged changes do not establish that a fix is available
in your installed version.

Independent community project. Not affiliated with or endorsed by Nintendo.
Original project and third-party attribution remain with their respective sources.

## Typography

Body text and controls use [Atkinson Hyperlegible Next](https://www.brailleinstitute.org/freefont/),
selected for readable, distinct letter shapes. The font is bundled locally under the
[SIL Open Font License](/Hookshot/fonts/atkinson/OFL.txt). Libertinus Serif is retained
for large headings; code uses monospace.
